# NordicStore

Tienda demo de electrónica: catálogo, carrito, pedidos, pagos (tarjeta, PayPal y Wompi en modo demo) y asistente de compra.

Sitio: [https://enithv.github.io/NordicStore/](https://enithv.github.io/NordicStore/)

API: [https://nordicstore-api.onrender.com](https://nordicstore-api.onrender.com) · [Swagger](https://nordicstore-api.onrender.com/swagger-ui/index.html)

## Demo

- `aiko` / `password` — compradora
- `lars` / `password` — administradora

El catálogo y el flujo de compra funcionan aunque el API esté iniciando (datos locales). Login, registro y admin requieren el API en línea.

## Local

Abre esta carpeta con Live Server. El API se ejecuta por separado desde `nordicstore-backend`.
